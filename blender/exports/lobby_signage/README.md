# Lobby · Commit 16

Пять грузовиков сохраняют оранжевые корпуса, козырьки, маячки и трапы. В стальную кассету на штатном креплении выведены карта, подсказка и счётчик. Клиент читает те же надписи, которые обновляет сервер очереди. При выгрузке новой геометрии отображаются прежние надписи.

Кремовые эмалевые шильды встроены во фронтоны двух лавок. Родственная вывеска на стальных подвесах обозначает вход в беседку. Доска рекордов стоит на деревянных опорах внутри ограждения, с металлическим козырьком и восемью строками. Порции снега вынесены в заголовок столбца, тысячи разделены пробелами.

## Установка и откат

- `../../lobby_signage.blend` — редактируемая модель. `../../lobby_signage.py` воспроизводит исходники и FBX. JSON рядом с FBX содержит размеры и материалы.
- В двух локальных RBXM лежат девять установленных моделей `LobbySignArt`. Их атрибут `MountPath` указывает родителя в `Workspace.Blockout`. При переносе сохранить мировую позицию и теги. Старые детали `Sign` и `Records.Board` оставить для локализации, обновления очереди и запасного отображения; при установке скрыть только их геометрию через `Transparency = 1`.
- В этой копии Lobby исходные детали и FBX-импорт сохранены в `ServerStorage._LobbySignsRollback`. Для отката снять вложенные `LobbySignArt` и восстановить прозрачность исходных деталей по `studio-placement.json`.

Доска рекордов стоит справа от кубка и развёрнута к проходу. При переносе `LobbyDirectoryRecords_Playable.rbxm` установить `Blockout.Records.Board.CFrame` по `installed.seats.Records.anchorCFrame` в `studio-placement.json`. Невидимая деталь служит резервной поверхностью и ориентирована по лицу доски. На кадрах `07-records-entry-before.jpg` и `08-records-entry-after.jpg` одна камера и одинаковые клиентские тестовые строки.
